## Descripción del Proyecto
Este repositorio contiene la implementación en código fuente ejecutable en **Python** correspondiente al **Taller 10**, desarrollado a partir del pseudocódigo diseñado previamente en el Deber 6.

El programa simula el flujo de arquitectura Cliente-Servidor mediante la construcción y envío de peticiones **HTTP (Método POST)** hacia un Servicio Web de Lenguaje de Alto Nivel (LLM / Inteligencia Artificial).
