## 1. Descripción del Proyecto
Resolución y desarrollo en pseudocódigo del Taller 10, enfocado en estructuras de control iterativas y manipulación de matrices.

## 2. Cómo ejecutar el código
1. Abrir el archivo de pseudocódigo (`.pse`) en el entorno **PSeInt**.
2. Presionar el botón **Ejecutar** (o la tecla `F9`).
3. Ingresar los datos requeridos por la consola.
